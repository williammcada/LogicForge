# LogicForge v0.4.2 — Round-Trip Contract

**Status:** Accepted import/export contract. This is not a claim that every mode/combination has been tested.

## Change

The platform must export a self-sufficient generation packet that lets a capable model return a valid import object without repeated screenshot/error-message repair cycles. The packet must state project/design revision, selected game mode, cultural-immersion level, required schema, field restrictions, validation rules, and import example.

## Must retain

- Suspect characteristics can be customized (for example, favorite coffee gas station) without confusing person names with object/place names.
- The guilty suspect is not predictably placed last.
- Evidence tracking is student-usable and supports deduction rather than implementation detail.

## Acceptance checks

| Check | Result |
| --- | --- |
| Exported packet identifies its selected game mode | Not run |
| Valid generated import passes without manual schema repair | Not run |
| Invalid import identifies the failing field and correction | Not run |
| Multiple puzzle/game/immersion combinations remain explicitly unverified until sampled | Not run |
